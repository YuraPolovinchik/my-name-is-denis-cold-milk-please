# MY NAME IS DENIS: COLD MILK, PLEASE

Законченная короткая 3D-игра от первого лица на Godot 4.4.1.

## Play in browser

[Запустить Web-версию](https://yurapolovinchik.github.io/my-name-is-denis-cold-milk-please/)

Web-версия рассчитана на современный Chrome, Edge или Firefox. Нужны компьютер,
клавиатура и мышь; первая загрузка может занять некоторое время.

## Быстрое управление

- `WASD` — движение;
- мышь — обзор;
- `ЛКМ` — взять или поставить предмет;
- `E` — взаимодействие и наливание;
- `ПКМ` — стабилизация при наливании;
- `Esc` — освободить мышь.

06:20 утра. Рита спит за закрытой дверью, созвон Wone IT уже идёт, а Денису
нужен растворимый кофе. Нужно пройти через квартиру, найти посуду, вскипятить
воду и вернуться к ноутбуку, выбирая между скоростью и тишиной.

## Запуск на Windows

1. Распакуйте архив в обычную папку.
2. Дважды нажмите `RUN_GAME.bat`.

Portable-версия Godot уже может лежать внутри папки `tools`. Если её нет,
лаунчер сам скачает официальный Godot 4.4.1 Standard и затем проверит проект
перед запуском. Отдельно устанавливать движок не нужно.

При самом первом запуске на несколько секунд появится консоль подготовки:
лаунчер импортирует встроенные звуки и сразу после проверки откроет игру.

`START_EDITOR.bat` открывает проект в редакторе. `RUN_TESTS.bat` запускает
автоматическую проверку без открытия окна игры.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` | ходьба |
| `Shift` | бег — быстро и громко |
| `C` | присесть |
| `Left Alt` | идти на носочках |
| `E` | обычное взаимодействие |
| удерживать `E` | медленное тихое взаимодействие |
| `Shift + E` | быстрое громкое взаимодействие |
| `ЛКМ` | взять предмет / бросить удерживаемый |
| `ПКМ` | аккуратно поставить предмет |
| `F3` | диагностический экран шума и квеста |
| `Esc` | освободить или снова захватить мышь |
| `R` | новый забег после финала |
| `P` | **фоторежим** — свободная камера для скриншотов |
| `Enter` | сделать скриншот (в фоторежиме) |
| `Space/C` | вверх/вниз (в фоторежиме) |

## Полное прохождение

1. В прихожей можно надеть тапочки.
2. На кухне открыть верхний шкаф и взять кружку.
3. Открыть кухонный ящик и взять банку растворимого кофе.
4. Взять чайник с подставки.
5. Поднести чайник к фильтру у мойки и нажать `E`.
6. Поставить чайник на круглую подставку и включить её.
7. Пока вода закипает, при необходимости вернуться к ноутбуку и ответить на вопрос.
8. Поставить кружку на жёлтую подставку рядом с чайником.
9. Взаимодействовать с жёлтой подставкой, чтобы заварить кофе.
10. Вернуться к ноутбуку и нажать `E`.

Телефон на кухонном столе начинает вибрировать примерно через полминуты.
Робот-пылесос включается позже, если заранее не отключить его расписание.
Оба объекта можно обезвредить до срабатывания.

## Проверка проекта

Ожидаемый результат `RUN_TESTS.bat`:

```text
DENIS_FOUNDATION_TESTS_OK
DENIS_COMPLETE_PROJECT_TESTS_OK
```

Тест проверяет загрузку всех скриптов, планировку комнат, мебель, физические
предметы, бытовые события и всю последовательность приготовления кофе до финала.

## Новые системы (v2.0)

### Система достижений
- 20+ достижений с прогрессом и сохранением
- Уведомления о разблокировке в реальном времени
- Достижения за скорость, тишину, экономику и особые действия

### Система сложности
- 4 уровня: Лёгкий, Нормальный, Сложный, Хардкор
- Влияет на: скорость пробуждения Риты, расход выносливости, шум

### Визуальные эффекты
- Частицы пыли при ходьбе по твёрдым поверхностям
- Искры и тряска камеры при падении предметов
- Пар от чайника при кипячении
- Хроматическая аберрация и виньетка при пробуждении Риты

### Фоторежим
- Активация клавишей `P`
- Свободная камера с регулируемой скоростью
- Сохранение скриншотов в `user://screenshots/`

### Система погоды
- Случайная погода: ясно, дождь, снег, туман
- Влияет на атмосферу и освещение

### Новые предметы
- **Умный чайник** — показывает температуру, индикация пара
- **Умный ТВ** — каналы с разной громкостью, визуализация помех
- **Шумоподавляющие наушники** — снижают шум, LED-индикатор заряда

### Система обучения
- Интерактивное обучение для новых игроков
- Пошаговые подсказки по управлению и механикам
- Возможность пропуска
